About This Project

This cluster repurposes 10 retired OnePlus 6T smartphones as a fully functional Kubernetes cluster. Each phone runs postmarketOS (a real Linux distribution for phones) with K3s (lightweight Kubernetes). The phones communicate over WiFi and run production workloads with automatic load balancing across all nodes. Built as a proof-of-concept for edge computing and sustainable tech reuse — giving old phones a second life as servers instead of e-waste.
