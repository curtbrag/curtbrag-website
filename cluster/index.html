About This Project

This cluster repurposes 10 retired OnePlus 6T smartphones as a fully functional Kubernetes cluster. Each phone runs postmarketOS (a real Linux distro) with K3s (lightweight Kubernetes). The phones communicate over WiFi and run production workloads like nginx, with automatic load balancing across all nodes. Built by Curtis Bragdon as a proof-of-concept for edge computing and sustainable tech reuse.
