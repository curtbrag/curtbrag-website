About This Project

This hybrid cluster combines 10 OnePlus 6T smartphones running postmarketOS, Windows PCs with WSL2, a Steam Deck, and PiKVM devices into a unified Kubernetes cluster. It runs K3s for container orchestration, Monero mining for passive income, and various home automation services. Built for edge computing, sustainable tech reuse, and learning.
